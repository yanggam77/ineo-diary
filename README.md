# 일기 쓰기, 어때요? — 『별일 없는 날에 일기 쓰기-저학년』 설문 · 서평단 모집

사계절출판사 슬기사전 15 『별일 없는 날에 일기 쓰기-저학년』 배본에 맞춰 진행하는
**저학년 어린이 일기 쓰기 설문 + 서평단(20가정) 신청** 웹앱입니다. (마케팅3팀 · 인어 @ineo_kids)

## 흐름
시작 → ① 학년 → ② 일기 쓰는 빈도 → ③ 그림일기 / 글 일기 → ④ 재미있어요 / 어려워요
→ ⑤ 이유(선택지 + 직접 쓰기) → 책 소개 → 서평단 안내·참여 여부 → 신청서(보호자 정보·개인정보 동의) → 완료

## 파일
- `index.html` — 설문 페이지 (이미지 포함 단일 파일)
- `apps-script/Code.gs` — 응답을 구글 시트에 저장하는 Apps Script

## 문구·일정 고치기
`index.html` 아래쪽 `var CONFIG = { ... }` 부분만 수정하면 일정, 활동 안내, 해시태그, 책 소개 문구가 바뀝니다.

## 응답 저장 (구글 시트)
1. 응답을 받을 구글 시트 → **확장 프로그램 → Apps Script**
2. `Code.gs`에 `apps-script/Code.gs` 내용 붙여 넣기
3. **배포 → 새 배포 → 웹 앱** (실행: 나 / 액세스: 모든 사용자) → `/exec` 주소 복사

이후 둘 중 하나로 운영합니다.
- **A. GitHub Pages 주소로 운영 (권장):** `index.html`의 `CONFIG.endpoint`에 `/exec` 주소를 넣고 커밋 → 깃허브 페이지 주소로 응답이 시트에 저장됩니다.
- **B. Apps Script 주소로 운영:** Apps Script에 HTML 파일 `Index`를 만들어 `index.html` 내용을 붙여 넣고 재배포 → `/exec` 주소로 바로 열립니다.

`endpoint`가 비어 있으면 **미리보기 모드**(저장 안 됨)로 동작합니다.
